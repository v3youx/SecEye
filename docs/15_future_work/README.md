# Future Work

Potential future improvements for SecEye include:

- Stronger command execution isolation.
- More robust command validation.
- Better structured tool definitions.
- Improved evidence collection.
- More advanced session context handling.
- Expanded test coverage.
- Improved reporting and finding organization.
- Support for additional LLM providers.
- Better error handling and observability.
- More controlled autonomous execution policies.

Future changes should preserve the project's core pipeline of analysis, validation, execution, output analysis, and reporting.
