# SecEye Overview

SecEye is an **LLM-Powered Autonomous Security Assessment Agent** designed to automate security assessment workflows through task analysis, tool selection, command execution, output analysis, and iterative assessment.

## Objectives

- Analyze a security assessment task.
- Select appropriate Kali/Linux security tools.
- Validate commands before execution.
- Execute assessment commands and collect results.
- Analyze technical output using an LLM.
- Decide whether further assessment is required.
- Generate a PDF containing security findings.

## Scope

SecEye is a CLI-based project intended for authorized security testing and controlled laboratory environments.
