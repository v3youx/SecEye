# Limitations

SecEye is an experimental autonomous security assessment project and has limitations.

## Current Limitations

- LLM decisions depend on the quality of prompts and tool output.
- Tool availability depends on the host environment.
- Command validation does not make arbitrary command execution completely safe.
- Output analysis depends on the information returned by assessment tools.
- API usage can introduce latency and token costs.
- Autonomous decisions should be reviewed in authorized testing environments.

These limitations should be considered before using SecEye for real assessments.
