# Security

SecEye is designed for authorized security assessment and controlled laboratory environments.

## Security Considerations

- Validate commands before execution.
- Do not assume missing target information.
- Do not invent command arguments.
- Keep API credentials outside source control.
- Treat LLM-generated commands as untrusted input.
- Restrict execution to authorized targets.

## Important

SecEye does not replace authorization, human oversight, or security testing procedures. Users are responsible for ensuring that every assessment is permitted.
